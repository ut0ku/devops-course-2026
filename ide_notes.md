# Git в VS Code vs Терминал

## Удобно в VS Code:
1. Graph — наглядная история коммитов и веток.
2. Diff в один клик — не нужно вводить git diff.
3. Publish/Sync — отправка на GitHub одной кнопкой.

## Удобнее в терминале:
1. Привычнее и быстрее — команды git add, git commit, git push уже отработаны, не нужно искать кнопки в интерфейсе.
